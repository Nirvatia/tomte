# Tomte // loves prompte

Локальный IDE-комбайн для сборки, управления и экспорта сложных промптов. Создан для тех, кто устал копировать простыни текста в чат к ИИ, вручную собирать контекст из репозитория и пытаться впихнуть невпихуемое в лимит токенов.

## Возможности

- **Мультимедийные промпты:** Вставляйте картинки и файлы прямо в текст. Tomte генерирует плейсхолдеры (`[IMAGE_1]`, `[FILE_1]`), чтобы нейросеть не пыталась халлюцинировать на основе бинарного мусора.
- **Дерево проекта (Project Tree):** Подключайте локальные папки (File System API) или GitHub-репозитории. Отмечайте галочками нужные файлы — Tomte сам посчитает токены и приложит их к промпту при экспорте.
- **Smart Code Extractor:** LLM выдала вам 15 блоков кода с комментариями "а вот тут измените"? Копипастить это в IDE — то ещё удовольствие. Экстрактор сам разрежет markdown-ответ на отдельные файлы и отдаст вам готовый ZIP-архив.
- **Экспорт во всё подряд:** Markdown, PDF, DOCX, PNG. Со встроенными лимитами, чтобы PDF-ник на 500 страниц не положил вам браузер.
- **Теги-шпаргалки:** Менеджер тегов для быстрого сохранения и вставки часто используемых инструкций (например, *"Не пиши тесты"* или *"Думай шаг за шагом"*).
- **Менеджер проектов:** Всё хранится локально в IndexedDB. Ваши гениальные (и не очень) идеи не улетят в облако и не станут тренировочной выборкой для очередной модели.
- **Оценка токенов в реальном времени:** StatusBar честно скажет, когда вы перешли черту и ИИ скоро ответит: *"Слишком много букв, сокращай"*.
