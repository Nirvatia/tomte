# Tomte

Штука для сборки промптов. Работает в браузере, всё хранит у тебя локально.

## Зачем это вообще

Знакомо: открыл чат с нейронкой, а дальше полчаса копируешь куски кода из разных файлов, руками рисуешь структуру папок, вставляешь скрины и прикидываешь, влезет ли это всё в лимит. Потом нейронка отвечает портянкой из пятнадцати блоков кода, и ты разносишь их по файлам тоже руками.

Tomte берёт эту рутину на себя:

1. Пишешь промпт в нормальном редакторе: заголовки, списки, таблицы, код.
2. Цепляешь папку с диска или GitHub-репу и галочками отмечаешь нужные файлы.
3. Кидаешь картинки и файлы. В тексте остаются метки `[IMAGE_1]`, `[FILE_1]`, чтобы было понятно, о чём речь.
4. Внизу видно, сколько примерно токенов выходит.
5. Жмёшь экспорт и забираешь один файл, где собрано всё.

И в обратную сторону: вставляешь ответ нейронки в экстрактор, он режет его по файлам и отдаёт ZIP.

## Что умеет

- **Редактор.** На Tiptap. Форматирование, таблицы, блоки кода, размер шрифта.
- **Проекты.** Каждый проект состоит из нескольких файлов-промптов, вложений и дерева. Переключаешься между ними, переименовываешь, дублируешь, удаляешь.
- **Дерево проекта.** Локальная папка через File System Access API или GitHub (публичный или с токеном). Отмеченные файлы уходят в экспорт. Дерево можно вставить в промпт текстом.
- **Карта кода.** Через tree-sitter вытаскивает из файлов сигнатуры функций и классов. Нейронке часто хватает этого вместо полного кода, а токенов уходит меньше.
- **Вложения.** Перетащил или вставил из буфера. Текст читается как текст, картинки как картинки.
- **Теги.** Заготовки фраз, которые пишешь в каждом втором промпте: «не трогай тесты», «отвечай коротко» и так далее. Вставляются в один клик.
- **Экспорт.** Markdown, PDF, DOCX, PNG. Стоят лимиты, чтобы браузер не лёг на огромном PDF.
- **Экстрактор кода.** Markdown-ответ с кучей блоков превращается в ZIP с файлами по местам.
- **Счётчик токенов.** Прикидка по символам, без токенайзера. Плюс-минус, но порядок показывает честно.

## Где лежат данные

В IndexedDB твоего браузера и больше нигде. Сервера нет, аккаунтов нет, аналитики нет. Есть и обратная сторона: почистишь данные сайта, и проекты пропадут. Бэкап пока не сделан, он есть в [ROADMAP.md](ROADMAP.md).

GitHub-токен, если ты его ввёл, тоже хранится локально, в настройках проекта, открытым текстом. Давай токен только на чтение.

## Стек

- Svelte 5 + SvelteKit
- Tiptap 3
- TailwindCSS 4
- IndexedDB через `idb`
- web-tree-sitter (WASM-грамматики лежат в `static/wasm`)
- docx, jspdf, modern-screenshot, fflate для экспорта
- Vite, TypeScript
- Vitest и Playwright для тестов

## Запуск

Нужны Node.js 18+ и npm 9+.

```bash
npm install
```

```bash
npm run dev
```

Открываешь адрес, который напишет Vite (обычно `http://localhost:5173`). Для работы с локальными папками нужен Chromium-браузер: в Firefox и Safari File System Access API нет.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер |
| `npm run build` | сборка |
| `npm run preview` | посмотреть собранное |
| `npm run check` | проверка типов (`svelte-check`) |
| `npm test` | юнит- и компонентные тесты (Vitest) |
| `npm run test:e2e` | e2e (Playwright) |
| `npm run check:wasm` | проверка совместимости WASM-грамматик |

## Структура

```
src/
  components/   UI по фичам: editor, project-tree, attachments, tags, export...
  lib/          Svelte-actions и конфиг Tiptap
  stores/       Svelte-сторы
  types/        общие типы
  utils/        логика: проекты, база, экспорт, GitHub, токены, экстрактор
tests/          тесты, раскладка повторяет src/
static/wasm/    грамматики tree-sitter
```
