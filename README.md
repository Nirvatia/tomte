# Tomte

Штука для сборки промптов. Работает в браузере, всё хранит у тебя локально.

## Зачем это вообще

Знакомо: открыл чат с нейронкой, а дальше полчаса копируешь куски кода из разных файлов, руками рисуешь структуру папок, вставляешь скрины и прикидываешь, влезет ли это всё в лимит. Потом нейронка отвечает портянкой из пятнадцати блоков кода, и ты разносишь их по файлам тоже руками.

Tomte берёт эту рутину на себя:

1. Пишешь промпт в нормальном редакторе: заголовки, списки, таблицы, код.
2. Цепляешь папку с диска или GitHub-репу и галочками отмечаешь нужные файлы.
3. Кидаешь картинки и файлы. В тексте остаются метки `[IMAGE_1]`, `[FILE_1]`, чтобы было понятно, о чём речь.
4. Внизу видно, сколько примерно токенов выходит.
5. Жмёшь «Предпросмотр» и смотришь, что в итоге уйдёт модели.
6. Жмёшь экспорт и забираешь один файл, где собрано всё.

И в обратную сторону: вставляешь ответ нейронки в экстрактор, он режет его по файлам, отдаёт ZIP или сразу пишет в твою папку.

## Что умеет

- **Редактор.** На Tiptap. Форматирование, таблицы, блоки кода, размер шрифта. Копирование и очистка текста прямо в тулбаре. Длинный текст прокручивается внутри редактора, строка состояния всегда на месте.
- **Проекты.** Каждый проект состоит из нескольких файлов-промптов, вложений и дерева. Переключаешься между ними, переименовываешь, дублируешь, удаляешь. Файлы открываются вкладками, а клик по плашке работает по всей её площади, а не только по тексту.
- **Дерево проекта.** Локальная папка через File System Access API или GitHub (публичный или с токеном). Отмеченные файлы уходят в экспорт. Дерево можно вставить в промпт отдельным блоком, скопировать или убрать из проекта одной кнопкой: текст и вложения при этом не трогаются. Есть поиск по дереву.
- **Фильтры выбора.** `.gitignore` корня учитывается сам. Плюс пресеты «только `src/`», «без тестов», «только код» и свои правила построчно. Отсеянные файлы в экспорт не попадают, даже если отмечены.
- **Карта кода.** Через tree-sitter вытаскивает из файлов сигнатуры функций и классов. Нейронке часто хватает этого вместо полного кода, а токенов уходит меньше.
- **Вложения.** Перетащил или вставил из буфера. Текст читается как текст, картинки как картинки.
- **Теги.** Заготовки фраз, которые пишешь в каждом втором промпте: «не трогай тесты», «отвечай коротко» и так далее. Вставляются в один клик. Много тегов не вытесняют редактор: панель прокручивается сама.
- **Шаблоны.** Пишешь `{{имя}}` в тексте, при экспорте выскакивает форма, и значения подставляются.
- **История версий.** Для каждого промпта хранится до 20 снимков. Смотришь построчный diff с текущим текстом и откатываешься.
- **Предпросмотр.** Большая кнопка-глаз в шапке рядом с настройками и экспортом. Показывает финальный промпт целиком.
- **Экспорт.** Markdown, PDF, DOCX, PNG. Есть DOCX по ГОСТ 7.32: Times 14, полуторный интервал, поля и нумерация страниц как положено. Стоят лимиты, чтобы браузер не лёг на огромном PDF.
- **Пачкой.** Отмечаешь несколько файлов-промптов и удаляешь их разом или скачиваешь ZIP с Markdown.
- **Экстрактор кода.** Лежит в боковой панели (на узких экранах в шапке). Markdown-ответ с кучей блоков превращается в ZIP с файлами по местам, либо пишется сразу в папку: перед записью покажет план «новый / изменён / без изменений».
- **Бэкап.** Проект выгружается в `.tomte.zip` и загружается обратно из менеджера проектов. GitHub-токен в архив не попадает.
- **Счётчик токенов.** Настоящего токенайзера нет: у Claude и Gemini его офлайн не достать. Считает по весам для каждого вида символов (буквы, кириллица, цифры, знаки, хеши), подогнанным под токенайзеры OpenAI по реальным файлам. Для текста и кода медианная ошибка около 6%, JSON и lock-файлы больше не занижаются в полтора раза. Это оценка, а не точный счёт. Лимит выбираешь по модели или вводишь свой.
- **Горячие клавиши и поиск.** `Ctrl/⌘+K` ищет файл промпта, `?` открывает шпаргалку. Остальное там же.
- **Темы.** Светлая, тёмная или как в системе. Светлая нейтрально-серая, без чисто белого, чтобы не слепила.
- **Обучение.** При первом запуске водит по интерфейсу. Повторить можно в настройках.
- **Офлайн.** Это PWA: ставится как приложение и работает без сети. Шрифты лежат в самой сборке, грамматики tree-sitter кэшируются при первом использовании.

## Языки

Русский, английский, испанский. При первом запуске язык берётся из браузера, переключается в настройках (шестерёнка в шапке, там же тема). Строки лежат в `src/lib/i18n/locales/`: сначала добавляешь в `ru.ts`, потом TypeScript сам потребует ту же строку в `en.ts` и `es.ts`.

## Где лежат данные

В IndexedDB твоего браузера и больше нигде. Сервера нет, аккаунтов нет, аналитики нет. Есть и обратная сторона: почистишь данные сайта, и проекты пропадут. Поэтому есть бэкап в `.tomte.zip`: сделай его перед тем, как чистить браузер.

GitHub-токен, если ты его ввёл, тоже хранится локально, в настройках проекта, открытым текстом. Давай токен только на чтение.

## Стек

- Svelte 5 + SvelteKit
- Tiptap 3
- TailwindCSS 4
- IndexedDB через `idb`
- web-tree-sitter (WASM-грамматики лежат в `static/wasm`)
- docx, jspdf, modern-screenshot для экспорта, fflate для ZIP и бэкапа
- svelte-sonner для уведомлений, шрифты Inter и JetBrains Mono из `@fontsource-variable`
- Сервис-воркер на `adapter-static`, без сервера
- Vite, TypeScript
- Vitest и Playwright для тестов

## Запуск

Нужны Node.js 18+ и npm 9+.

```bash
npm install
```

```bash
npm run dev
```

Открываешь адрес, который напишет Vite (обычно `http://localhost:5173`). Для работы с локальными папками нужен Chromium-браузер: в Firefox и Safari File System Access API нет.

## Команды

| Команда              | Что делает                            |
| -------------------- | ------------------------------------- |
| `npm run dev`        | dev-сервер                            |
| `npm run build`      | сборка                                |
| `npm run preview`    | посмотреть собранное                  |
| `npm run check`      | проверка типов (`svelte-check`)       |
| `npm run lint`       | ESLint                                |
| `npm run format`     | Prettier (`format:check` — проверка)  |
| `npm test`           | юнит- и компонентные тесты (Vitest)   |
| `npm run test:e2e`   | e2e (Playwright)                      |
| `npm run check:wasm` | проверка совместимости WASM-грамматик |

## Структура

```
src/
  components/   UI по фичам: editor, toolbar, project-tree, layout, header, tags, extractor...
  lib/          i18n, тема, горячие клавиши, обучающий тур, Svelte-actions, конфиг Tiptap
  stores/       Svelte-сторы
  types/        общие типы
  utils/        логика: проекты, база, экспорт, GitHub, токены, экстрактор, бэкап
tests/          юнит- и компонентные тесты, раскладка повторяет src/; e2e/ — Playwright
design/         макет интерфейса
static/wasm/    грамматики tree-sitter
```
